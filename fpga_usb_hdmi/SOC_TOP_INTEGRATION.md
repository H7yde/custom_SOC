# USB/HDMI inside soc_top

`soc_top.v` now instantiates the real `usb_hdmi_system` block design in
`gen_usb_hdmi/u_usb_hdmi_system`. It retains PicoRV32, CNN, UART, SPI, I2C and
the 16-bit parallel stream. The original 26 DDR, FIXED_IO and HDMI BD ports
connect to the physical top. Additional AXI/clock/reset ports stay internal
for the ARM/CNN bridge. USB0 uses PS MIO 28..39 and PHY reset MIO 46.

The PicoRV32/CNN clock remains H16 at 125 MHz. PicoRV32 uses SW0 reset;
CNN/bridge reset also includes the PS/video reset after the bridge addition.
PS/video uses the BD's independent FCLK and pixel clock/reset domains. The physical DDR
interface named `DDR_*` is separate from the PL stream named `ddr_*`.
PS controller x16 mode still requires the native generated x32 HDL port widths.

In an open Vivado project:

```tcl
source D:/LAB/custom_SOC-main/fpga_usb_hdmi/integrate_soc_top.tcl
```

This selects `soc_top`, `ENABLE_USB_HDMI=1`, the combined `soc_top.xdc`, and
the dedicated `synth_soc_usb_hdmi` / `impl_soc_usb_hdmi` runs. Existing
`impl_h16_core125_2/soc_top.bit` remains the old build. New bitstreams will be
under `SOC_HUFLIT_2026.runs/impl_soc_usb_hdmi/soc_top.bit` after implementation.
Use one job when launching runs. Reopen a previously open GUI project to load
changes made by batch Vivado before building.

Standalone firmware benches explicitly use `ENABLE_USB_HDMI=0` so they do not
need Zynq PS simulation models; hardware uses the default value 1.

Instantiation alone does not start a video stream. ARM boot/initialization must
configure PS clocks and DDR, VTC at 640x480/60 Hz, framebuffer and VDMA.
The subsequent [ARM/CNN bridge](ARM_CNN_BRIDGE.md) adds an AXI4-Lite aperture
and ownership control. A camera application is still required.
No board programming is performed by the integration script.

Validation runner: `build_check/check_soc_top_integration.tcl` synthesizes
the combined top and checks PS7, HDMI differential output buffers, CNN,
external ports and UCIO/NSTD pin constraints. Reports are stored beside it.

USB/HDMI integration verified before the ARM/CNN bridge, on 2026-10-31 with Vivado 2025.2:

- `SOC_TOP_USB_HDMI_SYNTHESIS_PASS` in `build_check/check_soc_top_integration.log`.
- PS7 present, at least four OBUFDS primitives present, CNN logic present.
- UCIO-1/NSTD-1: zero violations (`soc_top_integrated_pin_drc.rpt`).
- Synthesis resources: 8,990 LUTs, 9,253 registers, 11 BRAM tiles.
- Placement, routing, timing closure and a new integrated bitstream are not
  checked/generated by this synthesis validation.
